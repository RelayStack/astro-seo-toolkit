# RelayStack Lab

Small experiments, snippets and tooling notes from RelayStack (Basel).

## Layout

- `examples/` — minimal, runnable Cloudflare / web snippets
- `notes/` — short tooling notes
- `seo-toolkit/` — dependency-free SEO helpers: llms.txt generator, JSON-LD builders, IndexNow submitter

## Conventions

- Prefer Cloudflare primitives (Workers, Pages, D1, KV, R2) where they fit.
- German de-CH, Sie-form for client-facing copy; prices as "ab CHF".
